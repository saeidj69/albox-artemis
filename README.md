## Artemis

Artemis is a Next.js App Router application with Tailwind CSS v4, generated API clients (Orval), and a component system backed by Cursor rules.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run format
npm run format:fix
```

## Architecture (current + migration direction)

- `src/app`: route segments, layouts, and app-level wiring.
- `src/modules`: feature/domain UI and flow logic (legacy location during migration).
- `src/components`: shared composites.
- `src/lib`: shared UI primitives and helpers.
- `src/api`: generated by Orval (read-only, do not edit manually).

## Styling structure

- `src/app/globals.css`: entrypoint only (Tailwind/plugins + shared style imports).
- `src/shared/styles/tokens.css`: design tokens and theme variables.
- `src/shared/styles/base.css`: base element styles and global defaults.
- `src/shared/styles/typography.css`: typography utilities.
- `src/shared/styles/animations.css`: keyframes and animation utilities.

## API policy

- Generated API lives in `src/api` and is treated as read-only.
- Use generated hooks/functions/models directly from `src/api`.
- Keep runtime customization in mutator/provider configuration, not generated files.

## AI coding rules

Project rules are defined in `.cursor/rules/*.mdc` and include:

- architecture boundaries
- app-router conventions
- feature module conventions
- shared UI conventions
- style conventions
- API generated boundary policy
- auth server-guard conventions
- testing conventions
- naming and import-casing conventions
